# Restaurant Tips Analysis – Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a restaurant tips dataset to identify patterns and relationships that influence customer tipping behaviour.

## Objectives
- Analyze restaurant billing and tipping patterns.
- Explore the relationship between total bills and tips.
- Compare tipping behaviour across different categories.
- Identify correlations between numerical variables.
- Present meaningful insights through visualizations.

## Dataset
The dataset contains 244 records and 7 columns.

Key attributes:
- Total Bill
- Tip
- Gender
- Smoker Status
- Day
- Meal Time
- Party Size

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data loading and inspection
- Missing value and duplicate checking
- Statistical summaries
- Data visualization
- Correlation analysis
- Key findings

## Project Files
- `Restaurant_Tips_EDA.ipynb` – Complete analysis and visualizations
- `tips.csv` – Original dataset

## Conclusion
This project explores restaurant tipping behaviour using Python-based data analysis and visualization techniques. It helps identify patterns and relationships between customer bills, tips and other factors.
